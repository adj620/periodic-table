스마트폰 & PC 앱 설치 / 다운로드 안내

앱스토어 갈 필요 없이 터치 한 번으로 홈 화면에 설치하여 네이티브 앱처럼 사용하세요!

원클릭 설치 지금 바로 기기에 설치할 수 있습니다

브라우저 프롬프트를 통해 홈 화면에 아이콘을 바로 등록합니다.

🤖

안드로이드 (Galaxy, 픽셀 등)

  1. 크롬 / 삼성 인터넷 브라우저로 접속합니다.
  2. 우측 상단 또는 하단의 더보기(⋮ 또는 ≡)를 누릅니다.
  3. [앱 설치] 또는 [현재 페이지 추가 ➔ 홈 화면]을 터치합니다.
  4. 바탕화면에 생성된 원소 주기율표 앱을 언제든 바로 실행할 수 있습니다.
🍎

아이폰 & 아이패드 (iOS)

  1. Safari(사파리) 브라우저로 접속합니다.
  2. 화면 하단 중앙의 공유 아이콘 (네모 위 화살표 📤)을 터치합니다.
  3. 메뉴 스크롤 후 [홈 화면에 추가 ➕]를 선택합니다.
  4. 우측 상단 [추가]를 누르면 홈 화면에 앱 아이콘이 등록됩니다.
💻

PC (Windows / Mac)

  1. Chrome 또는 Edge 브라우저로 접속합니다.
  2. 상단 URL 주소창 우측 끝의 설치 아이콘(⊕ 또는 컴퓨터 모양)을 클릭합니다.
  3. 바탕화면 및 시작 메뉴에 독립 창으로 실행되는 앱이 등록됩니다.
🚀
인터넷 없이도 작동 (오프라인 지원)

핵심 원소 데이터와 퀴즈 엔진이 기기에 저장되어 비행기 모드나 오프라인에서도 작동합니다.

🔄
실시간 자동 업데이트 (무설치 갱신)

새로운 원소 데이터나 퀴즈 문제가 추가되면, 앱 실행 시 자동으로 최신 버전으로 갈아끼워집니다.
