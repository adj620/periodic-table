# ⚛️ 표준 대화형 & A4 맞춤 인쇄 원소 주기율표 (Interactive & Printable Periodic Table)

IUPAC 표준 명칭과 관용명(소듐-나트륨 등) 동시 표기, 원자량, 방사능(☢️) 표시, 118개 원소 실제 표본 사진, 7개 화학 계열 색상 분류 및 A4 1장/다기능 N장 맞춤 인쇄를 완벽 지원하는 웹 기반 표준 원소 주기율표 애플리케이션입니다.

---

## ✨ 핵심 기능

### 1. 🌟 종합 1장 완성형 주기율표 (최초 1+2편 통합본)
- **모든 핵심 정보 통합**: 원자번호, 방사능 ☢️ 표기, 원소 기호, 한글 표준명, 이명/관용명(`[나트륨]`, `[칼륨]`, `[동]`), 영문 공식명, 원자량이 한 타일에 모두 표시됩니다.
- **A4 가로 1장 완벽 출력**: 18×7 격자와 란타넘/악티늄족이 A4 가로 1장에 폰트/테두리 잘림 없이 완벽히 출력됩니다.

### 2. 📑 1~7편 다기능 테마 토글 및 N장 인쇄 스위트
동일한 18×7 격자 틀을 유지하면서 타일마다 서로 다른 화학·물리·역사 데이터를 담아 출력할 수 있습니다:
- **🌟 종합 1장판**: 1편+2편 통합 완성형 (원자번호, 기호, 한글, 이명, 영문, 원자량, 방사능)
- **1편 [기본명칭]**: 시원시원한 큰 기호, 한글 표준명, 영문명
- **2편 [원자량·이명]**: 원자량, 관용명/구명칭 강조, 오비탈 전자배치, 방사능 마크
- **3편 [열역학·밀도]**: 녹는점(℃), 끓는점(℃), 밀도, 상온 물리상태(고체/액체/기체)
- **4편 [산화수·결합]**: 주요 산화수(Oxidation States), 폴링 전기음성도
- **5편 [역사·용도]**: 발견연도, 발견자, 대표 실생활 및 첨단 산업 활용처
- **🎨 6편 [대표물건]**: 각 원소가 쓰인 실생활 대표 사물 이모지 & 대표 물건 명칭 포스터판
- **📸 7편 [실제사진]**: 118개 원소 실제 표본 사진 썸네일 & 실물 외형 및 광택 묘사

### 3. 🖥️ 대형 모니터 맞춤 가로세로 정비례 꽉 찬 화면 & 줌 조절
- **Aspect Ratio 1 : 1.15 고정**: 와이드 화면에서도 타일이 가로로 넙적해지거나 세로로 길어지지 않고 정사각형에 가까운 단정한 황금 비율을 유지합니다.
- **Container Query 비례 폰트**: 화면 확대 시 글씨와 아이콘도 정확하게 비례하여 시원시원하게 커집니다.
- **화면 맞춤 컨트롤**: `[ ➖ ]` 축소, `[ ➕ ]` 확대, `[ 🖥️ 꽉 찬 화면 ]` (화면 가로/세로 비율 연산 맞춤)

### 4. 🔍 실시간 검색 및 필터링
- 원소명, 이명(나트륨, 칼륨 등), 기호, 원자번호 실시간 검색
- ☢️ 방사성 원소만 모아보기 필터
- 7대 화학 계열 범례 클릭 시 해당 계열 하이라이트

### 5. 🔬 원소 상세 모달
- 원소 타일 클릭 시 고해상도 실제 표본 사진, 외형 특성, 실생활 대표 물건, 전자배치, 상세 물리화학적 특성을 모달창으로 확인 가능

## 🚀 실행 방법

### 요구사항
- Node.js (v18 이상 권장)

### 로컬 실행
```bash
# 1. 저장소 클론
git clone <저장소-URL>
cd periodic-table

# 2. 로컬 웹 서버 실행
node server.js

# 3. 브라우저 접속
# http://localhost:3000
```

## 🖨️ 인쇄 가이드
- **메인 페이지 1장 인쇄**: 상단 우측 `🖨️ 현재 편 인쇄 (1장)` 클릭
- **다기능 N장 일괄 인쇄**: 상단 우측 `📑 전체 N장 일괄 인쇄` 클릭
- **인쇄 설정 권장 옵션**:
  - 용지 크기: `A4`
  - 방향: `가로 (Landscape)`
  - 여백: `최소` 또는 `없음`
  - 배경 그래픽: `체크 (켜기)`
